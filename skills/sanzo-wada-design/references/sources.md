# Sources and scope

## Publisher (primary bibliographic source)
https://www.seigensha.com/books/978-4-86152-247-5/

Title: 配色事典―大正・昭和の色彩ノート. Author 和田三造 (Sanzo Wada). ISBN 978-4-86152-247-5. The publisher lists 348 combinations, 352 pages, A6 format, and explains its relation to 配色総鑑 (six volumes, beginning in 1933). Publisher page has a cover image and purchase links; it is not a free full-text edition. No full-book download is bundled in this skill.

## Online palette browser (community adaptation)
https://sanzo-wada.dmbk.io/

Interactive exploration of Wada combinations by Dain M. Blodorn Kim. Its conversion values and some memberships differ from the bundled corrected dataset; do not silently mix them. The website is not represented here as the publisher's official edition.

## Bundled dataset and license
https://github.com/mattdesl/dictionary-of-colour-combinations
https://raw.githubusercontent.com/mattdesl/dictionary-of-colour-combinations/master/colors.json
https://raw.githubusercontent.com/mattdesl/dictionary-of-colour-combinations/master/LICENSE.md

MIT License, Copyright (c) 2020 Matt DesLauriers; full text is retained in DATA-LICENSE.md. Upstream README retained in upstream-readme.md. Dataset derives from Dain M. Blodorn Kim's work and contains corrections. It uses U.S. Web Coated (SWOP) v2 CMYK and sRGB IEC61966-2.1 profiles with Relative Colorimetric and Black Point Compensation. Upstream explicitly warns that digital colors may differ from printed swatches.

The downloaded dataset was validated locally: 159 entries; combination IDs 1–348; each combination contains two, three, or four colors. See assets/provenance.json for retrieval timestamp and download-byte checksum. This is an offline snapshot, not a claim of permanent currentness.
